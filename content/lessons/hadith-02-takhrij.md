# 1. Qu'est-ce que le takhrîj ?

Dans le cadre pédagogique de TABAYYUN, le takhrîj consiste d'abord à :
- **Retrouver les sources** dans lesquelles un hadith est effectivement rapporté.

Puis, selon le niveau de recherche :
- Retrouver ses différentes formulations ;
- Identifier les chaînes principales ;
- Consulter les jugements des spécialistes ;
- Comparer les différentes voies.

Le takhrîj empêche une habitude extrêmement répandue :
> « J'ai trouvé le hadith sur un site, donc j'ai trouvé sa source. »

Non. Le site Internet est souvent seulement un intermédiaire.

---

# 2. Exemple concret de démarche

Tu reçois :
> « Le Prophète ﷺ a dit : … »

- **Étape 1 — Isoler quelques mots significatifs**  
  Choisir une expression relativement distinctive du récit.
- **Étape 2 — Rechercher les sources**  
  Chercher dans les recueils et bases documentaires.
- **Étape 3 — Identifier précisément le résultat**  
  Ne pas se contenter de *« rapporté par Muslim »*. Noter lorsque c'est possible : recueil, livre, chapitre, numéro selon le système de numérotation utilisé, Compagnon rapporteur.
- **Étape 4 — Comparer les formulations**  
  Deux occurrences apparemment identiques peuvent présenter des différences importantes.
- **Étape 5 — Rechercher les autres voies**  
  Un récit peut être transmis par plusieurs Compagnons, par plusieurs élèves d'un même transmetteur, ou sous plusieurs formulations.
- **Étape 6 — Consulter les jugements**  
  Le débutant ne doit pas inventer son propre verdict : il recherche ce qu'ont conclu les spécialistes compétents.

# 3. Source primaire et source secondaire

- **Source primaire** : Un ouvrage transmettant le récit avec sa chaîne (ex. : *Ṣaḥîḥ al-Bukhârî*, *Ṣaḥîḥ Muslim*, *Sunan Abî Dâwûd*, *Musnad Aḥmad*, *Muṣannaf ʿAbd ar-Razzâq*, etc.).
- **Source secondaire** : Un ouvrage ou une base qui renvoie vers les sources originales ou rassemble les jugements.

Les deux sont utiles, mais ils n'ont pas le même statut documentaire.

---

# 4. Numéro de hadith : attention

Un numéro n'est pas une identité absolue du hadith. Les systèmes de numérotation peuvent varier selon l'édition, le chercheur ou la base de données.  
TABAYYUN impose donc déjà le champ `numberingSystem`.  
Un référencement sérieux ressemble davantage à :  
> *Ṣaḥîḥ Muslim* — numéro X selon Muḥammad Fuʾâd ʿAbd al-Bâqî.  
qu'à une simple mention vague : *« Muslim n°X »*.

---

# 5. Le takhrîj n'est pas encore l'authentification

### ❌ Le piège
*« J'ai retrouvé le hadith dans un livre, donc il est ṣaḥîḥ. »*  
Un ouvrage de hadith peut contenir des récits authentiques, des récits faibles et différents niveaux de transmission. Retrouver le récit répond à : *« Où est-il rapporté ? »*, cela ne répond pas automatiquement à : *« Est-il authentique ? »*.
